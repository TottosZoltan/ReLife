# ReLife

Szöveges életszimulátor (BitLife-hangulat), telefonra optimalizálva. Böngészőben fut, telepítés nélkül.

Futtatás: nyisd meg az `index.html`-t, vagy kapcsold be a GitHub Pages-t. Telefonon a böngésző menüjéből "Hozzáadás a kezdőképernyőhöz" opcióval appként is használható.

## Karakterek
Lapos, idle-játékos stílusú, mellkasig látható karakterek (SVG, külön képfájl nélkül).
- 25 frizura: rövid, hosszú, feltűzött, nagyon rövid, göndör, félhosszú, lófarkas, tüskés, copfos, kopasz + afro, frufrus bubi, oldalra fésült, feltupírozott, magas konty, két konty, magas lófarok, két fonat, oldalfonat, hullámos hosszú, hosszú frufruval, tarajos, kopaszodó, középen elválasztott, pixie
- 10 testalkat: átlagos, karcsú, nyurga, izmos, atletikus, telt, nagydarab, zömök, körte formájú, apró
- A karakterkészítőben a frizura- és testalkat-gombok élő előnézetet mutatnak. A régi mentések változatlanul működnek.
- 16 ruhatípus: póló, pulcsi, kapucnis pulcsi, márkás polo, garbó, kardigán, trikó, csíkos póló, ing, blézer, melegítőfelső, sportmez, kantáros nadrág, farmerdzseki, bőrdzseki, mellény (8 színben)
- Kiegészítők (külön-külön kombinálhatók, közös színnel): fejfedők (baseball sapka, kötött sapka, halászsapka, kalap, szalmakalap, fejpánt, masni, virágkoszorú, bandana, macskafül, korona), fejhallgató / fülhallgató / headset / fülbevaló, szemüvegek (kerek, szögletes, napszemüveg), nyakra való (nyaklánc, sál, nyakkendő, csokornyakkendő)
- A karakterkészítőben a karakter képe és a név görgetés közben is felül marad, így azonnal látszik, mit változtat egy választás.
- Életkor szerinti megjelenés: a csecsemő pólyában van, kopaszon születik, majd apró pihék és kis tincs jelennek meg; a kisgyerek haja fokozatosan nő; a fej és a test fokozatosan kerül arányba. Tinédzserkorban (12–17) bőrproblémák, a fiúknál finom bajuszpihe jelenik meg; 18 éves kortól a nők alakja érett, felnőtt formát kap.
